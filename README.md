# Number Guessing Game

A simple, beginner-friendly number guessing project with three implementations:

- Python (console)
- Node.js (console)
- Web (HTML + JavaScript)

Each implementation includes:
- Random target number generation
- User input and validation
- Hints (too high / too low)
- Limited attempts mode and unlimited mode
- Option to play again

Get started quickly with whichever language/platform you prefer.

## Files in this project

- number_guess.py — Python console game
- node/ — Node.js console game
  - index.js
  - package.json
- web/ — Browser game
  - index.html
  - script.js
  - style.css

## Run instructions

### Python
Requires Python 3.7+.

Run:
```
python number_guess.py
```

### Node.js
Requires Node 14+.

Install (optional):
```
cd node
npm install
node index.js
```

### Web
Open `web/index.html` in a browser (double-click or serve with a static server).
